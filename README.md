# Postige — запуск сети мастеров

## Ветка `main`

Здесь находятся только утверждённые и готовые к использованию материалы: инструкции, сообщения, стандарты, шаблоны и другие документы, переданные в работу.

Все новые идеи, доработки и черновики создаются в ветке `draft`.

## Как переносить материал

1. Документ создаётся или дорабатывается в `draft`.
2. После согласования его изменения переносятся в `main`.
3. `main` всегда содержит только актуальную утверждённую версию.
