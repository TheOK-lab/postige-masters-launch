# Postige — запуск сети мастеров

Рабочая база запуска сети мастеров Postige в Украине.

## Цель

Проверить и запустить модель, в которой мастер:
1. получает нового клиента из смежной ниши;
2. качественно выполняет стрижку и правильный срез;
3. помогает продавцу показать ценность волос;
4. является независимым специалистом для продавца и покупателя;
5. получает отдельную оплату за работу с волосами.

## Карта репозитория

- `01-strategy` — решения, сегменты и метрики.
- `02-offer` — предложение и условия для мастера.
- `03-funnel` — путь от первого контакта до работы в сети.
- `04-content-and-ads` — рекламные заходы и материалы.
- `05-training-and-standards` — навыки и операционные стандарты.
- `06-database` — структура реестра и воронки, без персональных данных.
- `07-outreach` — поиск и первичная коммуникация.
- `08-assets` — готовые материалы для мастеров.
- `09-results` — отчёты, эксперименты и обратная связь.

## Правило работы

Каждое проверяемое решение фиксируется в `01-strategy/decisions-log.md`.
Контакты, номера телефонов, переписки и другие персональные данные хранятся в закрытой Google Sheets CRM, а не в этом публичном репозитории.
