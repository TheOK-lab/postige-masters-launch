# Лидогенерация

Всё, что помогает найти мастера и вызвать у него первичный интерес к Postige.

## Что складываем сюда

- рекламные хуки;
- Reels, посты и рекламные объявления;
- базы и источники поиска мастеров;
- сценарии первого касания;
- тесты рекламных креативов;
- результаты привлечения.

## Результат этапа
