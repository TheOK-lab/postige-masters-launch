# Воронка подключения мастера

```
Рекламный хук / рекомендация
→ статья или короткое видео
→ продающее видео о навыке и новой категории клиента
→ заявка мастера
→ короткий созвон
→ базовый материал и правила
→ первая проверка навыка
→ карточка мастера / первый клиент
→ обратная связь и повышение статуса
```

На каждом этапе фиксируем причину отказа или перехода в CRM.
