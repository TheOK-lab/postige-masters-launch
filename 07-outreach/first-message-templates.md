# Первое сообщение мастеру

## Вариант 1 — через навык

Здравствуйте. Мы запускаем Postige — независимую сеть мастеров для клиенток, которые продают волосы и меняют образ. Ищем мастеров, умеющих делать правильный срез и работать с клиентом бережно. Для мастера это отдельный профессиональный навык и новый тип клиента. Можно отправить короткое видео с идеей?

## Вариант 2 — через клиента

Здравствуйте. Postige ищет мастеров в вашем городе для клиенток, которые приходят на стрижку после продажи волос. Это не запрос на скидку: клиентка готова вложиться в смену образа, а работа с волосами оплачивается отдельно. Интересно посмотреть условия?
